# 十功能三批落地计划（v0.15.0 → v0.17.0）

按风险与价值分三批，每批独立验证（typecheck + 全部单测 + 冒烟 + 终端 e2e + 构建）+ 独立发版（tag/双包/Release 英文说明）。

---

## v0.15.0 · 可观测性（监控四件套）

### 0. 前置修复：接通 consumeSnapshot
`collectServer()`（ipc.cjs:46）广播快照处同步调用 `workbench.consumeSnapshot(payload)`——现有 GPU 空闲监视（watchSave）与告警规则（ruleSave，含迟滞/持续时间/冷却/静默时段）立即生效，事件走现有 event() → 系统通知 + workbench:event。

### 1. 日志监控（log watcher）
- workbench 新条目类型 `logs`：`{ id, serverId, name, path, patterns: string[](正则，每行一个), trackLoss: boolean, enabled, lastLines: string[](去重基线), lastLoss: number|null, lossPoints: number[](最近120点) }`，持久化进现有 workbench.json。
- 主进程 30s tick（与 tickSchedules 同层）：每 watcher 远程 `tail -n 60 -- path`，与 lastLines 后缀比对取新增行；命中 patterns 的行 → event('log-hit') 附最后几行；trackLoss 时按 `loss[=: \s]+([0-9.eE+-]+)` 提取数值入 lossPoints。
- UI：WorkCenter 新「日志」标签——表单（名称/路径/正则/是否跟踪 loss）、watcher 列表（最近命中行、loss sparkline 复用现有 Sparkline 组件）。

### 2. 环境一致性对比
- workbench 新 op `envCollect`：每台服务器一条 exec 收集 driver(`nvidia-smi --query-gpu=driver_version`)、CUDA(`nvcc --version`)、内核/发行版(`uname -r` + `/etc/os-release`)、Python(`python3 --version`)、PyTorch+CUDA 版本(`python3 -c "import torch;..."`，失败标记未装)，结果带时间戳缓存（复用 resource 队列的 per-server 去重模式）。
- UI：WorkCenter「系统」标签下新增「环境对比」卡——servers × 组件矩阵表，与多数值不一致的单元格琥珀色高亮；手动"重新收集"按钮。

### 3. 空闲 GPU 检测
- 在已接通的规则系统上新增 metric `occupiedIdle`：任一 GPU util < 阈值 且 memUsed/memTotal > 阈值（两者进 rule 的 threshold/recovery 字段语义化为 util%/mem%），持续 durationSeconds 触发；事件文案带卡号、占用用户、估算浪费时长。
- ruleSave 的 metric 白名单加入该值；UI 下拉同步。

### 4. 按用户 GPU·时长统计
- history-db 新表 `usage_minutes(day TEXT, server TEXT, user TEXT, gpu_minutes REAL, PRIMARY KEY(day,server,user))`；HistoryAggregator.ingestSnapshot 时对每张 GPU 取其 procs 去重用户集合，把采样间隔分钟数均摊给各用户并 upsert。
- workbench 新 op `usageReport(rangeDays)`：聚合查询返回 `[{ user, totalMinutes, byServer: {...} }]`；UI 挂在「报告」标签，复用现有 JSON/CSV 导出按钮模式。

## v0.16.0 · 效率四件套

### 5. 文件预览（图片/CSV）
- 新 IPC `sftp:readBinary`：读前 2MB 返回 base64 + 按扩展名猜 MIME（png/jpg/gif/webp/bmp）。
- FileManager：双击图片扩展名 → ImagePreview 对话框（data URL 渲染，支持缩放按钮 100%/适应）；双击 .csv → 客户端解析渲染前 100 行表格（超大文件截断提示）。TextViewer 保持纯文本职责。

### 6. 保存即上传（Dev Sync）
- workbench 新条目 `syncPairs`：`{ id, localDir, serverId, remoteDir, excludes: string[], enabled, lastSyncAt, lastFiles }`。
- 主进程：每对启用时 `fs.watch(localDir, { recursive: true })` + 500ms 去抖，变更文件（命中排除规则跳过）逐个调用现有 `transfers` 上传单文件（同目标路径覆盖语义已由 staging 引擎保证）。
- UI：WorkCenter 新「同步」标签——配对表单/列表/启停开关/最近同步文件；与目录同步(sync-planner)互补：那个是一次性预览确认，这个是持续盯盘。

### 7. 跨服务器命令历史
- `parallel:run` 执行时追加记录到 userData/command-history.json（上限 200 条 FIFO）：`{ id, at, command, servers: [name], source: 'parallel'|'snippet', ok }`。
- UI：并行命令页底部「历史」区——搜索框过滤、点击回填命令输入框、单条删除/清空。

### 8. 终端增强
- 安装 `@xterm/addon-search`：终端内 Ctrl+F 弹搜索条（上一个/下一个/关闭），复用 xterm 官方 addon。
- 会话条按服务器着色：serverId hash → 固定 hue，term-chip 左侧色条 + 展开面板边框同色，多机切换时防走错。

## v0.17.0 · 触达两件套

### 9. 手机状态页（只读）
- 主进程 `node:http` 服务器：默认关闭；设置页开关开启后监听 `0.0.0.0:<随机端口>`，生成随机 token。
- 两个路由：`/status.json?token=`（各服务器 GPU/显存/温度摘要 + 活跃传输 + 告警事件，无凭据无命令，纯只读）与 `/`（单文件内联 HTML+JS，深色移动端优先布局，5s 轮询，无构建步骤）。
- 设置页显示访问 URL（含局域网 IP 提示）与 token，一键复制；关闭即停服务器。UI 字符串进 10 语言词表。

### 10. 自动更新
- 安装 `electron-updater`，electron-builder 配 `publish: { provider: github, owner: Moguifeng-9119, repo: server-console }`。
- 行为：默认"仅通知"——启动后延时 30s 检查，发现新版本弹设置页横幅 + 系统通知（含版本号与更新日志首行）；设置页新增"自动下载并安装"开关，开启时下载完成后提示"退出时自动安装"。
- 因安装包未签名，Windows 首次运行更新仍有 SmartScreen 提示，Release 说明中写明。
