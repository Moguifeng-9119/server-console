# 后台任务定时计划（时间窗执行）· v0.14.1

按已确认的三个决策设计：**本软件主进程计时**（软件需运行才触发）、**窗口结束到点强制终止**、**按目标服务器本地时间**计算窗口。

## 核心模型

任务记录（workbench.json 中的 WorkspaceTask）扩展可选字段：

```ts
schedule?: {
  start: 'HH:MM';        // 窗口开始，如 '00:00'
  end: 'HH:MM';          // 窗口结束，如 '06:00'（支持跨夜，如 22:00–06:00）
  days: number[];        // 星期几生效（0=周日…6=周六），默认 [0,1,2,3,4,5,6]
  enabled: boolean;
  lastOccurrence?: string; // 上次触发的"窗口起始日" YYYY-MM-DD（防同窗重复启动）
  lastStartAt?: number;
}
```

新增任务状态值 `'stopped'`（被计划到点终止，区别于 succeeded/failed）。

## 后端（electron/workbench.cjs + ipc.cjs）

1. **taskSave 校验**：schedule 存在时校验 HH:MM 格式、start≠end、days 为 0–6 子集；已启动任务不可改 schedule（沿用现有 immutable 规则）。
2. **窗口判定**：复用现有 quiet() 的跨夜逻辑，封装 `windowState(schedule, serverDate, serverMinutes)` → 返回 `{ inside: boolean, occurrenceKey: string }`。跨夜窗口的 occurrenceKey 取**窗口开始那天**的日期（22:00–06:00 在凌晨 2 点属于前一天的窗口）。
3. **tickSchedules()**（主进程每 15 秒调用）：
   - 收集所有 enabled schedule 的 serverId；每个服务器远程 `date '+%F %H:%M'` 取服务器本地日期与时间（10 秒缓存，避免频繁往返；无 enabled 计划时零开销）。
   - **窗口内** && 任务非 live && `lastOccurrence ≠ occurrenceKey` → startTask(id)（复用现有 tmux/nohup 启动器），写 lastOccurrence，广播事件 `schedule-start` + 系统通知。
   - **窗口外** && 任务 live → killTask(id)，广播 `schedule-stop`。
   - 服务器连不上 → 跳过本轮，不写状态（下轮重试）。
4. **killTask(id)**（新方法）：tmux 模式 → `tmux kill-session -t sc-<remoteId>`；nohup 模式 → 读 runner.pid 并按 runner.start 校验防 PID 复用后 kill；置状态 `stopped`，写 finishedAt。
5. **taskStop 操作**（新 op，UI 手动停止用，计划终止复用同一实现）。
6. **ipc.cjs 接线**：workbench 构造处旁加 `setInterval(() => workbench.tickSchedules().catch(...), 15000)` + 启动时跑一次；事件经现有 onEvent → broadcast('workbench:event') → 渲染层自动刷新。

## UI

7. **挂载 WorkCenter**（当前处于未接线状态，功能做完用户也看不到）：App.tsx 侧栏新增「任务」入口（view kind 'workcenter'），onTerminal → 打开该服务器终端 tab；onFiles → 打开文件 tab；onForward → 打开设置（端口转发区）。nav 标签进 en/zh-CN 词表。
8. **WorkCenter 任务页扩展**：
   - 表单新增「定时执行」区：启用开关、开始/结束时间（`<input type=time>`）、星期选择（7 个切换钮，默认每天）。
   - 任务卡：计划徽章（⏰ 00:00–06:00 · 每天/工作日/周X）；定时未触发状态显示「等待窗口」；live 任务新增**停止**按钮（taskStop）。
   - 新字符串走现有 `label('key', fallback)` 模式，en/zh-CN 补 `features.*` 键，其余语言回退英文。

## 测试（新增 tests/workbench-schedule.test.cjs）

- 窗口判定：常规窗、跨夜窗、边界（含=起点、不含=终点）、days 过滤
- occurrenceKey 归属（跨夜窗口在凌晨属于前一天）
- 同一窗口内不重复启动（lastOccurrence 去重）
- 窗口外到点 killTask（tmux kill-session 命令断言）
- disabled 永不触发；服务器 date 查询失败不崩溃、不改状态
- taskStop 手动停止
