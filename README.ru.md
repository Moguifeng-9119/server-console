## Для каких задач

ServerConsole — персональный настольный инструмент для общих серверов **Linux / NVIDIA GPU**. По SSH объединяет поиск ресурсов, терминал, двухпанельный SFTP и передачу между серверами. Удалённый агент мониторинга не нужен.

- Фильтры свободных GiB на каждой GPU, модели и пользователя; сортировка по свободной памяти и прямой переход к мониторингу, терминалу или файлам.
- Показатели GPU/процессов, несколько GPU для одного PID, разности временных счётчиков CPU Linux и реальные метки времени с пропусками измерений.
- Очередь передачи, проверенное возобновление, восстановление после перезапуска, прямой rsync или ретрансляция SFTP.
- Импорт SSH config, группы, ProxyJump, команды и проброс портов. Активные/завершённые предупреждения, до двух закрываемых уведомлений; демо не отправляет внешние уведомления об аномалиях.

Нет командных аккаунтов, резервирования ресурсов, планировщика кластера, телеметрии AMD/Intel GPU и полной диагностики NVML. Свободная память — наблюдение, а не бронь.

## Начало работы

Скачайте пакет своей ОС из [релиза](https://github.com/Moguifeng-9119/server-console/releases/tag/v0.12.0). Проверьте подключение и добавьте сервер либо импортируйте SSH config. Для GPU нужен удалённый nvidia-smi, для системных метрик — Linux /proc. Исходный код запускается с Node.js 22 и npm:

```sh
git clone https://github.com/Moguifeng-9119/server-console.git
cd server-console
npm ci
npm run dev
```

В браузере работает явно обозначенная демонстрация. Настоящие SSH, учётные данные, терминалы и SFTP требуют настольного процесса:

```sh
npm run electron:dev
```

Укажите нужные свободные GiB на карту, модель или пользователя, затем откройте мониторинг, терминал или файлы. Настройки разделены на оформление, мониторинг, безопасность, рабочие процессы и активность/справку. Ctrl/Cmd+K открывает палитру; основные диалоги поддерживают Tab, Shift+Tab, Escape и восстановление фокуса.

## Передача и учётные данные

- Произвольный существующий файл назначения не используется для возобновления. Задачи SFTP имеют собственные временные файлы; весь существующий префикс сравнивается по SHA-256.
- Перед заменой проверяются число байтов, размер и время изменения источника. Пересекающиеся пути обрабатываются последовательно. Ошибки сохраняют данные для повторной попытки; при сбое очистки после отмены/удаления запись восстановления сохраняется и ошибка показывается.
- Необязательный MD5 проверяется до замены отдельного файла. Каталоги и ретрансляции не объявляются проверенными MD5.
- Прямая передача требует rsync на обеих сторонах и доступа от источника к получателю. Использует временный SSH-ключ и доверенный отпечаток; иначе применяется SFTP с промежуточными файлами. Варианты tar/scp с непосредственной перезаписью отключены.
- Пароли и парольные фразы шифруются при безопасном системном хранилище ключей. Если его нет либо используется Linux basic_text, новые секреты остаются только в памяти сессии и вводятся вновь после перезапуска. Настройки показывают реальный режим; закрытые ключи остаются по исходным путям.

См. [безопасность](SECURITY.md). Размер/время не блокируют параллельно изменяемый источник. rsync между реальными удалёнными серверами ещё не проверен.

## Что проверено

v0.11.1 прошла на Windows, Linux и macOS отдельно проверку типов, 84 регрессионных теста, SFTP smoke, сборку и 22 браузерные проверки. Упакованное приложение на каждой ОС прошло 16 нативных проверок: IPC, локальная SSH-оболочка, изменение размера, проброс портов и перезапуск с аутентификацией. Windows DPAPI проверен реально; macOS использует MockKeychain, а не проверку настоящего Keychain. Linux проверяет хранение только в сессии при отсутствии безопасного хранилища. macOS запускалась на arm64; Intel не запускался.

Физические GPU/MIG, полный удалённый PTY, производственный rsync/сетевая скорость, настоящие хранилища macOS/Linux, установщики и обновления требуют отдельных испытаний. Бенчмарк 10/30 имитационных локальных SSH-сессий не доказывает скорость кластера или процент экономии. См. [результаты](docs/VALIDATION-0.11.1.md) и [методику](docs/BENCHMARKS.md).

## Разработка и сборка

React, TypeScript, Electron, Vite и ssh2; точные версии указаны в [package.json](package.json) и файле блокировки. Команды проверки:

```sh
npm run lint
npm run typecheck
npm test
npm run smoke
npm run build
npx playwright-core install chromium
npm run test:ui
npm run test:workflow
npm run benchmark
```

Укажите SC_ELECTRON_PATH на актуальный распакованный исполняемый файл и запустите npm run e2e:terminal. dist:win:lite, dist:win:nsis, dist:linux и dist:mac отключают автоматическую публикацию. [CI пакетов](.github/workflows/package.yml) проверяет приложение до загрузки неподписанных файлов. ESLint и React-Hooks настроены; npm run lint выполняется в CI.
