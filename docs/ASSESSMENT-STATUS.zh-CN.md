## 本次五个注意点

| 注意点 | 处理结果 | 证据与边界 |
| --- | --- | --- |
| 崩溃后 `.scpart-<hash>` 残留 | 持久化 staging journal：写入前登记、重启恢复、取消/移除清理、断连失败保留记录并重连重试 | 真机强杀传输进程后恢复、重启后的远端清理通过；只删除已证明归属的精确路径 |
| 前缀 SHA-256 看起来卡住 | 独立校验字节/文件数量进度，折叠任务也可见，可暂停/取消 | 完整双流校验保留；校验读数不计入传输字节。100 GB 取消与早关闭有控制流回归，未测 100 GB 真机耗时 |
| 总览轮询不降速 | 保留合理设计 | `activeServerId=null` 全量采集；只有详情页降低后台频率 |
| 旧任务 error 难懂 | 带原因的暂停记录，不猜测执行参数；特定旧合成 error 迁移为说明 | 真实错误保留；无归属证据的旧远端 stage 不自动删除；“仅移除旧记录”只清 metadata |
| README 丢失新手细节 | 十语言首页均链接中英文详细指南，恢复源码树、传输决策图、崩溃/清理规则、排错与开发说明 | 十页 README 有实质正文；详细技术指南本身是中英文 |

## 原七项内核缺陷

| 原问题 | 实现与证据 | 验证边界 |
| --- | --- | --- |
| 同名短目标误作断点 | 任务专属暂存、完整 SHA-256 前缀与最终字节检查 | 一台真实 Linux 主机上传/下载通过；跨机 rsync 待验 |
| 恢复缺 serverId/路径 | 独立执行参数与 journal 补回尚未 debounce 落盘任务 | 真机子进程强杀→新管理器恢复→续传通过；整包 Electron 强杀另验 |
| TOFU 关闭后不持久化 | 原子保存；坏信任库或写失败拒绝连接 | 回归及原生重启证据 |
| CPU% 用负载 | `/proc/stat` 差分，未知值保留 | 合成计数与真机采样通过；独立系统工具对照待验 |
| PID 多 GPU 覆盖 | 保留多卡数组并显示关联 | 回归通过；真实 NCCL/DDP/MIG 待验 |
| 历史丢稳定点/猜时间 | 时间戳、时间权重、缺口保留，无时间戳旧历史丢弃 | 回归和原生持久化证据 |
| Base64 降级声称加密 | OS 安全后端或仅会话，显示实际模式 | Windows DPAPI 实测；Linux basic_text 仅会话；macOS MockKeychain 不等于真实 Keychain |

## 工程、真机与产品范围

新增独立 stage-journal、transfer-staging、resume-verifier 模块，拆出归属、清理恢复与校验流。ESLint/Hooks 已配置并通过，恢复与语言契约新增回归，三系统 CI 增加文件/编辑/互传/语言工作流并保存回执。后端仍为 checkJs，没有声称全面 strict TypeScript 或全面拆分 IPC。

一台授权 Docker 六张 H100 已实测采集；16 MiB 上传/下载 SHA-256、强杀恢复和真实 stage 清理通过。另一台 Docker 两次远端关闭连接，跨机 rsync、断网临时 SSH 密钥清理、真实网络吞吐待验。笔记本 5070 Ti Laptop 只读 nvidia-smi 确认；未新增 Windows 本机 GPU 监控。

发布/平台以 [验证记录](VALIDATION-0.12.0.md) 为准。未签名/未公证、Intel macOS 执行、真实 macOS/Linux 密钥库、安装器/更新器、远程 PTY、实际 10/30 主机性能仍有独立验收边界。

完整 NVML/MIG、进程树诊断、团队 SSO/RBAC、资源预约、集群调度当前未提供，是更深能力或新的产品范围。后续顺序见 [路线图](ROADMAP.md)。
