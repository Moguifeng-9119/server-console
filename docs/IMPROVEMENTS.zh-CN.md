# 0.11.0 项目改进记录

这一轮围绕“找到合适 GPU 后直接开始 SSH 工作”调整产品体验，并修复会误导监控判断或损坏传输目标的具体问题。公开 GitHub 仓库和 Release 尚未更新，本记录对应本地源码与 Windows 预览。

| 角度 | 已落地的变化 | 对使用者的意义 |
| --- | --- | --- |
| 吸引力与定位 | README 首屏突出任务、下载入口、实际新版截图，说明个人 Linux/NVIDIA 工作台定位 | 初次访问能看懂项目适合谁、如何开始 |
| 外观与布局 | 新资源工作台、主题一致的卡片、宽屏八卡四列、整齐指标行、分类设置、窄屏适配 | 信息更容易比较，减少被密集设置遮挡 |
| 使用流程 | 单卡空闲显存/型号/用户筛选，直达监控/终端/文件，告警中心、可关闭提示 | 从找卡到工作更少点击，异常有明确入口 |
| 监控内核 | CPU 使用 /proc/stat 时间差，多卡 PID 保留全部关联，真实时间戳历史与缺采样间隔、过期提示 | 不再把负载当 CPU 利用率，避免历史和离线旧数据误导 |
| 传输可靠性 | 独立任务临时文件、SHA-256 前缀续传、源版本/字节数检查、校验后替换、路径冲突互斥、完整恢复记录 | 任意旧目标不会被错当断点，错误和取消保留已有完整目标 |
| 安全与错误反馈 | 无安全后端时新凭据只存会话，坏文件保留并阻止覆盖，信任库损坏/写失败拒绝连接，配置写失败内存列表不变 | 真实保存模式与失败原因可见，减少静默丢失配置或放宽信任 |
| 工程与开源维护 | 行为/浏览器/原生回归、10/30 会话实测基准、三系统检查 CI、手动打包、架构/贡献/安全/路线图/问题模板 | 改动更容易验证、复现和接手；性能承诺有明确证据边界 |

本地通过 8 个测试文件共 76 项行为测试、类型检查、双假服务器真实 SFTP 冒烟、生产构建、22 项浏览器检查、9 项 Windows 打包原生检查。原生检查比对全部 Electron CJS 与生产资源 SHA-256，证明测试对象对应当前源码；shell 断言使用计算输出，避免把输入回显当执行成功。

10/30 个本机模拟 SSH 会话的热采集中位数分别为 19.56/45.93 ms。这包含假服务器和客户端，不含 Electron 渲染，也没有真实网络时延，不能当成真实集群或竞品性能胜出证据。

主要页面维护英文与简体中文，其他语言新增文本回退英文。旧导入器/文件/终端部分文案、真实 GPU、远端 rsync、macOS/Linux 包、系统密钥库、签名/安装器/更新器仍有明确待验收项。
